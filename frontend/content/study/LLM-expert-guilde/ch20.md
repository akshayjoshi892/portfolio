## 20.1 `GPTConfig` and the Module Layout

### 🧭 The Problem First
A model has many hyperparameters (layers, width, heads, context length, vocabulary, dropout, bias). Scattered magic numbers make experiments error-prone and weights impossible to reload.

### 💡 Intuition / Instinct
Put every architectural choice in one **config dataclass**. The model is a pure function of the config, which makes checkpoints self-describing (save the config with the weights) and sweeps trivial. Mirror GPT-2's module names (`transformer.wte`, `transformer.h.0.attn.c_attn`) so you can load its weights directly.

### 🖼️ Visual Mental Model

```text
 GPT
 ├── transformer
 │   ├── wte  : Embedding(V, C)       token embeddings
 │   ├── wpe  : Embedding(T, C)       position embeddings
 │   ├── drop : Dropout
 │   ├── h    : ModuleList[Block × L]
 │   └── ln_f : LayerNorm(C)
 └── lm_head  : Linear(C, V) (tied to wte)
```

### 📐 The Math, Gently
Configs used in the book (the size ladder from front matter):

| name | L | H | C | T | params (V=2K / 50K) |
|---|---|---|---|---|---|
| nano | 4 | 4 | 128 | 256 | 0.8M / 7M |
| micro | 6 | 6 | 384 | 256 | 10.7M / 30M |
| mini | 8 | 8 | 512 | 1024 | 25M / 51M |
| small (GPT-2) | 12 | 12 | 768 | 1024 | 86M / 124M |

### 🛠️ Build It From Scratch

```python
# nanoforge/models/gpt.py (top of file)
from dataclasses import dataclass, asdict

@dataclass
class GPTConfig:
    block_size: int = 256        # max context length T
    vocab_size: int = 2048       # V (pad to a multiple of 64)
    n_layer: int = 4             # L
    n_head: int = 4              # H
    n_embd: int = 128            # C
    dropout: float = 0.0
    bias: bool = True            # GPT-2 uses biases; Llama doesn't

CONFIGS = {
    "nano":  dict(n_layer=4,  n_head=4,  n_embd=128, block_size=256),
    "micro": dict(n_layer=6,  n_head=6,  n_embd=384, block_size=256),
    "mini":  dict(n_layer=8,  n_head=8,  n_embd=512, block_size=1024),
    "small": dict(n_layer=12, n_head=12, n_embd=768, block_size=1024),
}
```

### 🔬 Experiment & Observe
`GPTConfig(**CONFIGS["micro"], vocab_size=2048)`. Compute the params with `gpt_params` (Ch 19.6) *before* building the model.

### ⚠️ Failure Modes & Debugging
- Changing the config between saving and loading → shape mismatch. Always save `asdict(cfg)` inside the checkpoint.
- `n_embd % n_head != 0` → assertion.

### 🧠 Expert Insight
nanoGPT (Karpathy, 2022) uses this exact structure. HF `GPT2Config` has the same fields under different names (`n_positions`, `n_ctx`).

## 20.2 Embeddings → Blocks → Final Norm → Head

### 🧭 The Problem First
Assemble the full forward pass with the `(B,T) → (B,T,V)` interface, an optional loss, and an efficient inference path.

### 💡 Intuition / Instinct
1. Token embedding + position embedding → the initial residual stream.
2. L blocks (communicate + compute).
3. Final LayerNorm.
4. LM head → logits. During training compute logits at all T positions (T predictions per sequence); during generation only the last position is needed.

### 🖼️ Visual Mental Model

```text
 idx (B,T) → wte (B,T,C) + wpe (T,C) → drop → [Block]×L → ln_f → lm_head → logits (B,T,V)
                                                                        ↘ CE vs targets (B,T)
```

### 📐 The Math, Gently
$\text{loss} = \frac{1}{BT}\sum_{b,t} -\log\text{softmax}(\text{logits}_{b,t})_{y_{b,t}}$: every position is a training example, so each sequence gives T examples.

### 🛠️ Build It From Scratch

```python
# nanoforge/models/gpt.py (continued: the full model)
import math, inspect
import torch, torch.nn as nn, torch.nn.functional as F
from nanoforge.models.attention import CausalSelfAttention

class MLP(nn.Module):
    def __init__(self, n_embd, dropout=0.0, bias=True):
        super().__init__()
        self.c_fc = nn.Linear(n_embd, 4 * n_embd, bias=bias)
        self.c_proj = nn.Linear(4 * n_embd, n_embd, bias=bias)
        self.c_proj.RESIDUAL_SCALE = True
        self.drop = nn.Dropout(dropout)
    def forward(self, x):
        return self.drop(self.c_proj(F.gelu(self.c_fc(x), approximate="tanh")))

class Block(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.ln_1 = nn.LayerNorm(cfg.n_embd, bias=cfg.bias)
        self.attn = CausalSelfAttention(cfg.n_embd, cfg.n_head, cfg.block_size, cfg.dropout, cfg.bias)
        self.ln_2 = nn.LayerNorm(cfg.n_embd, bias=cfg.bias)
        self.mlp = MLP(cfg.n_embd, cfg.dropout, cfg.bias)
    def forward(self, x):
        x = x + self.attn(self.ln_1(x))
        x = x + self.mlp(self.ln_2(x))
        return x

class GPT(nn.Module):
    def __init__(self, cfg: GPTConfig):
        super().__init__()
        self.cfg = cfg
        self.transformer = nn.ModuleDict(dict(
            wte=nn.Embedding(cfg.vocab_size, cfg.n_embd),
            wpe=nn.Embedding(cfg.block_size, cfg.n_embd),
            drop=nn.Dropout(cfg.dropout),
            h=nn.ModuleList([Block(cfg) for _ in range(cfg.n_layer)]),
            ln_f=nn.LayerNorm(cfg.n_embd, bias=cfg.bias),
        ))
        self.lm_head = nn.Linear(cfg.n_embd, cfg.vocab_size, bias=False)
        self.transformer.wte.weight = self.lm_head.weight          # weight tying (Ch 19.5)
        self.apply(self._init_weights)                               # Section 20.3

    def forward(self, idx, targets=None, all_logits=False):
        B, T = idx.shape
        assert T <= self.cfg.block_size, f"sequence length {T} > block_size {self.cfg.block_size}"
        pos = torch.arange(T, device=idx.device)                     # (T,)
        x = self.transformer.wte(idx) + self.transformer.wpe(pos)    # (B,T,C) + (T,C)
        x = self.transformer.drop(x)
        for block in self.transformer.h:
            x = block(x)                                             # (B,T,C)
        x = self.transformer.ln_f(x)
        if targets is not None or all_logits:
            logits = self.lm_head(x)                                 # (B,T,V)
            if targets is None: return logits, None
            loss = F.cross_entropy(logits.view(-1, logits.size(-1)).float(), targets.view(-1), ignore_index=-100)
        else:
            logits = self.lm_head(x[:, [-1], :])                     # (B,1,V): only last position
            loss = None
        return logits, loss

    def num_params(self, non_embedding=True):
        n = sum(p.numel() for p in self.parameters())
        return n - self.transformer.wpe.weight.numel() if non_embedding else n
```

- `ignore_index=-100` lets you mask positions (padding, prompts in SFT; Ch 37).

### 🧠 Expert Insight
Computing logits only for the last position at inference saves V×C×(T−1) FLOPs per step, which is significant for large vocabularies. The KV cache (Ch 30) removes the rest of the redundant compute.

> **Core intuition:** *Each sequence is T lessons at once: predict every next token in parallel.*

## 20.3 Initialization Scheme: Scaled Residual Init

### 🧭 The Problem First
PyTorch's default inits are not tuned for transformers. The residual stream's variance grows with each of the 2L residual additions, so the initial logits and loss get too large as depth increases.

### 💡 Intuition / Instinct
GPT-2 recipe:
- All Linear and Embedding weights ~ N(0, 0.02); biases 0.
- Projections *into* the residual stream (`attn.c_proj`, `mlp.c_proj`) get std $0.02/\sqrt{2L}$, so the 2L additions sum to roughly unit-scale variance growth instead of 2L×.

### 🖼️ Visual Mental Model

```text
 stream variance at init:
   without scaling:  Var grows ≈ 1 + 2L·σ²_branch
   with 1/√(2L):     Var grows ≈ 1 + σ²_branch      (depth-independent)
```

### 📐 The Math, Gently
If each of the 2L branches adds independent variance $s^2$: total $= \text{Var}(x_0) + 2Ls^2$. Scaling the branch output weights by $1/\sqrt{2L}$ divides each branch's variance by 2L, so the total grows by only ~$s^2$.

### 🛠️ Build It From Scratch

```python
# inside class GPT
    def _init_weights(self, module):
        if isinstance(module, nn.Linear):
            std = 0.02
            if getattr(module, "RESIDUAL_SCALE", False):
                std *= (2 * self.cfg.n_layer) ** -0.5
            nn.init.normal_(module.weight, mean=0.0, std=std)
            if module.bias is not None: nn.init.zeros_(module.bias)
        elif isinstance(module, nn.Embedding):
            nn.init.normal_(module.weight, mean=0.0, std=0.02)
```

### 🔬 Experiment & Observe
Build a 24-layer model with and without `RESIDUAL_SCALE`. Measure the final residual-stream std and the initial loss. Without scaling, the stream std grows with depth and the initial loss rises above ln V.

### ⚠️ Failure Modes & Debugging
`self.apply(self._init_weights)` runs *after* tying, so the tied matrix is initialized as an Embedding and a Linear (the last one wins; both are std 0.02, so it's harmless).

### 🧠 Expert Insight
GPT-2 paper, Section 2.3: "scale the weights of residual layers at initialization by 1/√N". Modern variants: µP (Ch 26) uses width-dependent inits; some models init `c_proj` to zero, making each block start as the identity.

### ✅ Check Your Instinct
1. Std for c_proj with L = 12?

<details><summary>Answers</summary>

1. 0.02/√24 ≈ 0.0041.
</details>

### 📌 Recap Card
- N(0, 0.02) everywhere; zero biases.
- Residual projections scaled by $1/\sqrt{2L}$.
- Check: initial loss ≈ ln V.

> **Core intuition:** *Each block should start as a whisper so that 100 whispers don't become a roar.*

## 20.4 Training on Tiny Shakespeare, Then TinyStories

### 🧭 The Problem First
Now we train it for real: efficient data loading from the tokenized `.bin`, a proper optimizer setup, evaluation, generation, and checkpoints.

### 💡 Intuition / Instinct
The training script is the Ch 7.5 loop plus: memory-mapped data, AdamW with param groups (Ch 8.6), warmup + cosine LR (preview of Ch 24), gradient clipping, periodic eval and samples, and checkpoints. Keep it minimal now; Part 6 makes it production-grade.

### 🖼️ Visual Mental Model

```text
 .bin (uint16 ids) ─memmap─▶ random windows (B,T+1) ─▶ x,y ─▶ GPT ─▶ loss ─▶ AdamW
       every eval_interval: estimate_loss(train,val), sample, save ckpt
```

### 📐 The Math, Gently
Tokens per step = B × T. With B = 32 and T = 256, that's 8,192 tokens/step; 5,000 steps = 41M tokens ≈ 70 epochs over Shakespeare (~600K BPE tokens). That is heavy repetition, so dropout helps here.

### 🛠️ Build It From Scratch

```python
# nanoforge/data/memmap.py
import numpy as np, torch
class MemmapData:
    def __init__(self, path, block_size, device="cpu", dtype=np.uint16):
        self.path, self.T, self.device, self.dtype = path, block_size, device, dtype
    def get_batch(self, B):
        data = np.memmap(self.path, dtype=self.dtype, mode="r")     # re-open each call avoids memory leak
        ix = torch.randint(len(data) - self.T - 1, (B,))
        x = torch.stack([torch.from_numpy(data[i:i + self.T].astype(np.int64)) for i in ix])
        y = torch.stack([torch.from_numpy(data[i + 1:i + 1 + self.T].astype(np.int64)) for i in ix])
        if self.device == "cuda":
            return x.pin_memory().to("cuda", non_blocking=True), y.pin_memory().to("cuda", non_blocking=True)
        return x.to(self.device), y.to(self.device)
```

```python
# scripts/train_gpt_basic.py
import math, time, torch
from dataclasses import asdict
from nanoforge.models.gpt import GPT, GPTConfig, CONFIGS
from nanoforge.data.memmap import MemmapData
from nanoforge.optim import make_param_groups
from nanoforge.tokenizer.regex_bpe import RegexBPE
from nanoforge.sampling import generate
from nanoforge.utils import set_seed, get_device

set_seed(1337); dev = get_device()
tok = RegexBPE().load("tokenizers/shakespeare_2k.json")
V = ((tok.vocab_size + 63) // 64) * 64                     # pad vocab to multiple of 64
cfg = GPTConfig(**CONFIGS["micro"], vocab_size=V, dropout=0.2)
model = GPT(cfg).to(dev)
print(f"params: {model.num_params()/1e6:.2f}M")
train = MemmapData("data/processed/shakespeare_train.bin", cfg.block_size, dev)
val = MemmapData("data/processed/shakespeare_val.bin", cfg.block_size, dev)

max_steps, warmup, lr_max, lr_min, B = 5000, 200, 1e-3, 1e-4, 32
opt = torch.optim.AdamW(make_param_groups(model, 0.1), lr=lr_max, betas=(0.9, 0.95), fused=(dev == "cuda"))
def lr_at(s):
    if s < warmup: return lr_max * (s + 1) / warmup
    p = (s - warmup) / (max_steps - warmup)
    return lr_min + 0.5 * (lr_max - lr_min) * (1 + math.cos(math.pi * p))

@torch.no_grad()
def evaluate(iters=50):
    model.eval(); out = {}
    for name, d in [("train", train), ("val", val)]:
        out[name] = sum(model(*d.get_batch(B))[1].item() for _ in range(iters)) / iters
    model.train(); return out

t0 = time.time()
for step in range(max_steps + 1):
    for g in opt.param_groups: g["lr"] = lr_at(step)
    x, y = train.get_batch(B)
    with torch.autocast(device_type=dev if dev != "mps" else "cpu", dtype=torch.bfloat16, enabled=(dev == "cuda")):
        _, loss = model(x, y)
    opt.zero_grad(set_to_none=True); loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0); opt.step()
    if step % 500 == 0:
        L = evaluate()
        print(f"step {step:5d} | train {L['train']:.3f} val {L['val']:.3f} | lr {lr_at(step):.2e} | {time.time()-t0:.0f}s")
        s = generate(model, torch.tensor([tok.encode("ROMEO:")], device=dev), 100, cfg.block_size, temperature=0.8, top_k=50)
        print(tok.decode(s[0].tolist()))
torch.save({"model": model.state_dict(), "config": asdict(cfg)}, "checkpoints/gpt_micro_shakespeare.pt")
```

## 20.5 Loading GPT-2 Weights Into Your Own Code

### 🧭 The Problem First
How do you know your implementation is *exactly* right? A subtle bug (a wrong GELU approximation, a transposed weight, a misplaced LayerNorm) might only cost a little quality and go unnoticed.

### 💡 Intuition / Instinct
Load OpenAI's trained GPT-2 weights into your model and compare its logits with the reference implementation (HF Transformers) on the same input. If they match to ~1e-4, every component is correct. One gotcha: GPT-2's original code uses a `Conv1D` layer that stores weights **transposed** relative to `nn.Linear`, so those weights must be transposed when loading.

### 🖼️ Visual Mental Model

```text
 HF GPT2LMHeadModel state_dict ──(rename, transpose Conv1D)──▶ your GPT
 same input ids ──▶ both models ──▶ compare logits (max abs diff ~1e-4) ✓
```

### 📐 The Math, Gently
Conv1D computes $y = xW + b$ with W: (in, out). `nn.Linear` computes $y = xW^\top + b$ with W: (out, in). So $W_{linear} = W_{conv}^\top$.

### 🛠️ Build It From Scratch

```python
# inside class GPT
    @classmethod
    def from_pretrained(cls, model_type="gpt2"):
        from transformers import GPT2LMHeadModel               # used ONLY as a weight source
        sizes = {"gpt2": (12, 12, 768), "gpt2-medium": (24, 16, 1024),
                 "gpt2-large": (36, 20, 1280), "gpt2-xl": (48, 25, 1600)}
        L, H, C = sizes[model_type]
        cfg = GPTConfig(n_layer=L, n_head=H, n_embd=C, vocab_size=50257, block_size=1024, bias=True, dropout=0.0)
        model = cls(cfg); sd = model.state_dict()
        hf = GPT2LMHeadModel.from_pretrained(model_type).state_dict()
        hf = {k: v for k, v in hf.items() if not k.endswith((".attn.masked_bias", ".attn.bias"))}
        transposed = ("attn.c_attn.weight", "attn.c_proj.weight", "mlp.c_fc.weight", "mlp.c_proj.weight")
        for k, v in hf.items():
            if k not in sd: continue
            with torch.no_grad():
                if k.endswith(transposed):
                    assert v.shape[::-1] == sd[k].shape, k
                    sd[k].copy_(v.t())
                else:
                    assert v.shape == sd[k].shape, (k, v.shape, sd[k].shape)
                    sd[k].copy_(v)
        return model
```

```python
    ours_logits, _ = ours(ids, all_logits=True)                 # (1, T, V)
    ref_logits = ref(ids).logits

```

- Change `approximate="tanh"` to the exact GELU: the diff grows to ~1e-3. Tiny, but detectable. That is what an exact match check buys you.
- Plot the singular value spectrum of `transformer.h.5.mlp.c_fc.weight` (Ch 3.6).

### ⚠️ Failure Modes & Debugging
- Missing a transpose → shape assertion (good) or, for square matrices (c_proj of attention is C×C!), *silent* garbage. The assertion can't catch square cases, so the logits comparison is essential.
- HF buffers (`attn.bias` masks) must be skipped.
- Vocab 50257 is not padded here, to match the weights exactly.

### 🧠 Expert Insight
Matching a reference implementation numerically is standard practice when porting models between frameworks (e.g. HF ↔ Megatron ↔ JAX). Frontier labs have entire test suites for "numerics parity".

2. What's the relationship between Conv1D and Linear weights?

<details><summary>Answers</summary>

1. It's square (C×C), so both orientations have the same shape.
2. They are transposes of each other.
</details>

### 📌 Recap Card
- Load GPT-2 weights: rename, transpose the Conv1D weights.

- Square matrices hide transpose bugs; compare outputs.

> **Core intuition:** *If real GPT-2 runs correctly inside your code, your code is GPT-2.*

## 20.6 Ablations: Remove a Component and Watch What Breaks

### 🧭 The Problem First
You've read claims like "residuals are essential" and "position matters". Instinct comes from *seeing* it on your own model.

### 💡 Intuition / Instinct
Run controlled experiments: the same data, steps, seed and config, removing one component at a time. Compare the validation loss. **Predict each outcome before running it.** This is the most valuable hour of the chapter.

### 🛠️ Build It From Scratch

```python
# scripts/ablate.py
import copy, torch, torch.nn as nn
from nanoforge.models.gpt import GPT, GPTConfig, CONFIGS, Block

class NoResidualBlock(Block):
    def forward(self, x):
        x = self.attn(self.ln_1(x)); return self.mlp(self.ln_2(x))
class NoNormBlock(Block):
    def forward(self, x):
        x = x + self.attn(x); return x + self.mlp(x)
class NoAttnBlock(Block):
    def forward(self, x): return x + self.mlp(self.ln_2(x))

def build(variant, cfg):
    m = GPT(cfg)
    if variant in ("no_residual", "no_norm", "no_attn"):
        cls = {"no_residual": NoResidualBlock, "no_norm": NoNormBlock, "no_attn": NoAttnBlock}[variant]
        for i, b in enumerate(m.transformer.h):
            nb = cls(cfg); nb.load_state_dict(b.state_dict()); m.transformer.h[i] = nb
    if variant == "no_pos":
        nn.init.zeros_(m.transformer.wpe.weight); m.transformer.wpe.weight.requires_grad_(False)
    if variant == "one_head":
        cfg2 = copy.deepcopy(cfg); cfg2.n_head = 1; m = GPT(cfg2)
    return m
# Train each variant with the loop from 20.4 (same seed, 2000 steps) and record final val loss.
VARIANTS = ["baseline", "no_pos", "no_residual", "no_norm", "no_attn", "one_head"]
```
