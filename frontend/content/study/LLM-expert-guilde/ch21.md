## 21.1 "Data Is the Model": What Pretraining Corpora Contain

### 🧭 The Problem First
You can copy an architecture from a paper in a day. Two models with identical architectures but different data can differ enormously in capability. What is actually in the data, and in what proportions?

### 💡 Intuition / Instinct
A model is a compressed mirror of its training distribution (Ch 5.7). It can only know what's in the data, and it overweights whatever the data overweights. Typical ingredients:
- **Web crawl** (Common Crawl): huge and diverse, but noisy (spam, boilerplate, duplicates).
- **Code** (GitHub): reasoning structure, precision, tool use.
- **Books:** long-range coherence, narrative.
- **Scientific papers** (arXiv, PubMed): technical knowledge, math.
- **Encyclopedic** (Wikipedia): dense facts.
- **Conversational/forums** (StackExchange, Reddit): Q&A structure.
- **Math** (curated web math, textbooks): reasoning.

### 🖼️ Visual Mental Model

```text
 Example modern mix (by tokens, illustrative):
 web ████████████████████████████████ 60–80%
 code ████████ 10–20%
 math/science ███ 5%
 books/wiki/other ██ 5%
 + late-stage "annealing" on the highest-quality subsets
```

### 📐 The Math, Gently
Token budget math: a Chinchilla-optimal 1B model needs ~20B tokens (Ch 26); modern small models are trained on 1–15T tokens ("overtrained" for inference efficiency). One CC snapshot ≈ 3–5 billion pages; after filtering and dedup, FineWeb kept ~15T tokens from 96 snapshots.

Training on data you have never looked at. Always sample, read and histogram before training.

- **Li et al. (2024), DataComp-LM (DCLM):** a model-based quality filter was the single most important factor.
- **Gunasekar et al. (2023), "Textbooks Are All You Need" (Phi-1):** high-quality synthetic and filtered data rivals much larger models.

## 21.2 Ethical, Legal and Licensing Considerations; robots.txt

### 🧭 The Problem First
Scraping everything you can reach may violate copyright, terms of service, privacy law (GDPR) and site owners' wishes, and can put private data into your model.

### 💡 Intuition / Instinct
Treat data like any other dependency with a licence:
1. **Prefer openly licensed or public-domain data** (Wikipedia CC-BY-SA, Project Gutenberg, permissively licensed code, government documents).
2. **Respect robots.txt and rate limits** when crawling.
3. **Track provenance:** keep URL/source and licence metadata for every document.
4. **Minimize personal data** (Ch 22.3) and honour opt-outs.
5. For your own/company data: get explicit permission.

This isn't legal advice. Laws vary by country and are evolving, so consult counsel for commercial use.

### 🖼️ Visual Mental Model

```text
 every document: {text, source, url, license, crawl_date, lang, hash} → auditable pipeline
```

### 📐 The Math, Gently
No math. A useful metric is the **coverage of provenance** (% of tokens with known licence/source). Aim for 100%.

### 🛠️ Build It From Scratch

```python
# nanoforge/data/crawl.py
import time, urllib.robotparser, urllib.request, urllib.parse
USER_AGENT = "nanoforge-edu-crawler/0.1 (contact: you@example.com)"
_rp_cache = {}
def allowed(url):
    root = "{0.scheme}://{0.netloc}".format(urllib.parse.urlparse(url))
    if root not in _rp_cache:
        rp = urllib.robotparser.RobotFileParser(root + "/robots.txt")
        try: rp.read()
        except Exception: return False
        _rp_cache[root] = rp
    return _rp_cache[root].can_fetch(USER_AGENT, url)
def polite_get(url, delay=1.0, timeout=15):
    if not allowed(url): return None
    time.sleep(delay)
    req = urllib.request.Request(url, headers={"User-Agent": USER_AGENT})
    with urllib.request.urlopen(req, timeout=timeout) as r:
        if "text/html" not in r.headers.get("Content-Type", ""): return None
        return r.read().decode("utf-8", errors="replace")
```

## 21.3 Scraping and Text Extraction (Removing HTML Boilerplate)

### 🧭 The Problem First
A raw web page is 80–95% navigation menus, ads, cookie banners, scripts and footers. Training on that teaches the model to generate "Accept all cookies | Privacy Policy | © 2024".

### 💡 Intuition / Instinct
Extract the **main content**: drop `<script>`, `<style>`, `<nav>`, `<footer>`, `<aside>`; then keep the text blocks with high *text density* (lots of words, few links). Boilerplate is link-dense and repeated across pages; content is word-dense and unique.

### 🖼️ Visual Mental Model

```text
 <html> nav(links:20 words:25) │ article(links:3 words:900) │ footer(links:15 words:40)
 link density:      0.8        │          0.003             │          0.4
 keep ────────────────────────▶ article only
```

### 📐 The Math, Gently
Link density of a block = (words inside `<a>`) / (total words). Keep blocks with density < 0.33 and ≥ 10 words (heuristics in the style of jusText/trafilatura).

### 🛠️ Build It From Scratch

```python
# nanoforge/data/extract.py
from html.parser import HTMLParser
import re

DROP = {"script", "style", "nav", "footer", "header", "aside", "form", "noscript", "svg", "iframe"}
BLOCK = {"p", "div", "li", "h1", "h2", "h3", "h4", "h5", "h6", "pre", "blockquote", "td", "section", "article"}

class _Extractor(HTMLParser):
    def __init__(self):
        super().__init__(); self.blocks, self.cur, self.link_words, self.skip, self.in_a = [], [], 0, 0, 0
    def handle_starttag(self, tag, attrs):
        if tag in DROP: self.skip += 1
        elif tag == "a": self.in_a += 1
        elif tag in BLOCK: self._flush()
    def handle_endtag(self, tag):
        if tag in DROP: self.skip = max(0, self.skip - 1)
        elif tag == "a": self.in_a = max(0, self.in_a - 1)
        elif tag in BLOCK: self._flush()
    def handle_data(self, data):
        if self.skip: return
        words = data.split()
        if not words: return
        self.cur.extend(words)
        if self.in_a: self.link_words += len(words)
    def _flush(self):
        if self.cur: self.blocks.append((" ".join(self.cur), self.link_words / len(self.cur)))
        self.cur, self.link_words = [], 0

def extract_main_text(html, min_words=8, max_link_density=0.33):
    p = _Extractor(); p.feed(html); p._flush()
    keep = [t for t, ld in p.blocks if len(t.split()) >= min_words and ld <= max_link_density]
    text = "\n\n".join(keep)
    return re.sub(r"[ \t]+", " ", text).strip()
```

```python
<article><h1>Why the sky is blue</h1><p>Sunlight is scattered by molecules in the atmosphere, and

<footer><a href=/p>Privacy</a> <a href=/t>Terms</a> © 2024</footer><script>var x=1;</script></html>"""
```

## 21.4 Normalization: Unicode, Whitespace, Language ID

### 🧭 The Problem First
The same text can appear in many byte forms: different Unicode normalizations, invisible characters, mixed line endings, mojibake ("Ã©" for "é"). This wastes tokens, breaks dedup, and confuses the model. You also need to know the *language* of each document to build a mix.

### 💡 Intuition / Instinct
Canonicalize before anything else: fix mojibake, apply NFC normalization, strip control and zero-width characters, normalize line endings and excess whitespace. Then **identify the language** (a character n-gram classifier) so you can route, filter and balance.

### 🖼️ Visual Mental Model

```text
 "Café\r\n\r\n\r\n​" → NFC → "Café" + "\n\n"   (1 canonical form)
 language ID: character n-gram profile → {"en": 0.97}
```

### 📐 The Math, Gently
A naive Bayes language ID: $\hat L = \arg\max_L \sum_{g \in \text{ngrams}(x)} \log P(g\mid L)$ with smoothed char-trigram probabilities per language.

### 🛠️ Build It From Scratch

```python
# nanoforge/data/clean.py
import re, unicodedata, math
from collections import Counter

_CTRL = re.compile(r"[\u0000-\u0008\u000B\u000C\u000E-\u001F\u007F​-‏  ﻿]")
def fix_mojibake(s):
    try:
        fixed = s.encode("latin-1").decode("utf-8")
        return fixed if fixed.count("�") <= s.count("�") else s
    except (UnicodeEncodeError, UnicodeDecodeError):
        return s

def normalize_text(s):
    s = fix_mojibake(s)
    s = unicodedata.normalize("NFC", s)
    s = s.replace("\r\n", "\n").replace("\r", "\n")
    s = _CTRL.sub("", s)
    s = re.sub(r"[ \t]+\n", "\n", s)            # trailing spaces
    s = re.sub(r"\n{3,}", "\n\n", s)            # collapse blank lines
    return s.strip()

class CharNgramLangID:
    """Tiny naive-Bayes language identifier over char trigrams."""
    def __init__(self, n=3): self.n, self.models = n, {}
    def _grams(self, s):
        s = f"  {s.lower()}  "; return [s[i:i + self.n] for i in range(len(s) - self.n + 1)]
    def fit(self, samples: dict):                # {"en": "long text...", "fr": "..."}
        for lang, text in samples.items():
            c = Counter(self._grams(text)); tot = sum(c.values()); V = len(c) + 1
            self.models[lang] = (c, tot, V)
        return self
    def predict(self, s):
        scores = {}
        for lang, (c, tot, V) in self.models.items():
            scores[lang] = sum(math.log((c[g] + 1) / (tot + V)) for g in self._grams(s[:2000]))
        m = max(scores.values()); z = sum(math.exp(v - m) for v in scores.values())
        return {k: math.exp(v - m) / z for k, v in scores.items()}
```


### 🔬 Experiment & Observe

### ⚠️ Failure Modes & Debugging
- Aggressive normalization (NFKC) changes meaning in some contexts (e.g. superscripts "x²" → "x2", full-width forms). NFC is the safe default.
- Language ID on code or tables gives confident nonsense. Set a confidence threshold (e.g. 0.65).

- **Joulin et al. (2016), fastText** (lid.176); **Kargaran et al. (2023), GlotLID**.
- `ftfy` (fixes text for you) is the standard mojibake repair library.

## 21.5 Exact Dedup (Hashing) and Near-Dedup With MinHash + LSH

### 🧭 The Problem First
The web is massively duplicated: copied articles, templates, mirrors, boilerplate licence text. Duplicates cause (1) wasted compute, (2) **memorization** and regurgitation of repeated text, and (3) **test contamination**. Exact hashing catches only byte-identical copies. Near-duplicates (same article, different ads or dates) need something smarter.

### 💡 Intuition / Instinct
- **Exact dedup:** hash each normalized document (or line/paragraph); keep the first of each hash.
- **Near dedup:** represent each doc as a set of word n-grams ("shingles"). Two docs are near-duplicates if their sets have high **Jaccard similarity**. Comparing all pairs is O(N²), impossible at billions of documents. **MinHash** compresses each set into a short signature whose agreement rate estimates Jaccard, and **LSH** buckets signatures so that only likely-similar pairs are compared.

### 🖼️ Visual Mental Model

```text
 doc → shingles {"the cat sat", "cat sat on", ...}
     → MinHash signature [h1_min, h2_min, ..., h128_min]     (P[match] = Jaccard)
     → split into 16 bands × 8 rows → hash each band → buckets
 docs sharing ANY band bucket → candidate pair → verify → keep one per cluster
```

### 📐 The Math, Gently
Jaccard: $J(A,B) = \frac{|A\cap B|}{|A\cup B|}$.
MinHash property: for a random hash h, $P[\min h(A) = \min h(B)] = J(A,B)$.
LSH with b bands of r rows: $P[\text{candidate}] = 1 - (1 - J^r)^b$. This S-curve has its threshold near $(1/b)^{1/r}$.
Example: b = 16, r = 8 gives a threshold ≈ $(1/16)^{1/8} ≈ 0.71$. With J = 0.9: P = 1 − (1 − 0.43)^16 ≈ 0.9999. With J = 0.5: P = 1 − (1 − 0.0039)^16 ≈ 0.06.

### 🛠️ Build It From Scratch

```python
# nanoforge/data/dedup.py
import hashlib, re, struct
import numpy as np
from collections import defaultdict

def exact_hash(text: str) -> str:
    return hashlib.sha1(re.sub(r"\s+", " ", text.lower()).strip().encode("utf-8")).hexdigest()

def exact_dedup(docs):
    seen, out = set(), []
    for d in docs:
        h = exact_hash(d["text"])
        if h not in seen: seen.add(h); out.append(d)
    return out

def shingles(text, n=5):
    w = re.findall(r"\w+", text.lower())
    return {" ".join(w[i:i + n]) for i in range(max(1, len(w) - n + 1))}

_MERSENNE = (1 << 61) - 1
class MinHasher:
    def __init__(self, num_perm=128, seed=0):
        rng = np.random.default_rng(seed)
        self.a = rng.integers(1, _MERSENNE, num_perm, dtype=np.uint64)
        self.b = rng.integers(0, _MERSENNE, num_perm, dtype=np.uint64)
        self.num_perm = num_perm
    def signature(self, shingle_set):
        if not shingle_set: return np.full(self.num_perm, _MERSENNE, dtype=np.uint64)
        hv = np.array([struct.unpack("<Q", hashlib.sha1(s.encode()).digest()[:8])[0] & _MERSENNE
                       for s in shingle_set], dtype=np.uint64)                  # (S,)
        # universal hashing (a*x + b) mod p for all permutations at once; use Python ints to avoid overflow
        a, b = self.a.astype(object), self.b.astype(object)
        mins = [min(((int(ai) * int(x) + int(bi)) % _MERSENNE) for x in hv) for ai, bi in zip(a, b)]
        return np.array(mins, dtype=np.uint64)

def jaccard(a, b): return len(a & b) / max(1, len(a | b))
def est_jaccard(sa, sb): return float((sa == sb).mean())

class LSHIndex:
    def __init__(self, bands=16, rows=8):
        self.b, self.r, self.tables = bands, rows, [defaultdict(list) for _ in range(bands)]
    def insert_and_query(self, key, sig):
        cands = set()
        for i in range(self.b):
            band = sig[i * self.r:(i + 1) * self.r].tobytes()
            bucket = self.tables[i][band]
            cands.update(bucket); bucket.append(key)
        return cands

def near_dedup(docs, threshold=0.8, num_perm=128, bands=16, n=5):
    mh, lsh, sigs, keep = MinHasher(num_perm), LSHIndex(bands, num_perm // bands), {}, []
    for i, d in enumerate(docs):
        sig = mh.signature(shingles(d["text"], n)); sigs[i] = sig
        cands = lsh.insert_and_query(i, sig)
        if any(est_jaccard(sig, sigs[j]) >= threshold for j in cands):
            continue                                           # near-duplicate of an earlier kept/seen doc
        keep.append(d)
    return keep
```

```python
base = "The quick brown fox jumps over the lazy dog near the river bank on a sunny afternoon in May. " * 5
docs = [{"text": base}, {"text": base.replace("sunny", "cloudy")}, {"text": "Completely different text about neural networks and gradient descent. " * 5}]
A, B = shingles(docs[0]["text"]), shingles(docs[1]["text"]); mh = MinHasher()
print("true J:", round(jaccard(A, B), 3), "est J:", est_jaccard(mh.signature(A), mh.signature(B)))
print("kept:", len(near_dedup(docs)))                       # 2
```

### 🔬 Experiment & Observe
- Plot the LSH S-curve $1 - (1-J^r)^b$ for (b, r) = (16, 8), (32, 4), (8, 16). Pick the curve that matches your threshold.

### ⚠️ Failure Modes & Debugging
- Shingle size too small (n = 1–2): unrelated docs look similar. Too large (n = 13): paraphrased copies are missed. n = 5 words is typical.
- Very short documents have unstable Jaccard. Handle them separately (exact hash only).
- Deduplicating *after* splitting into train/val lets duplicates leak across splits. **Dedup first, then split.**

### 🧠 Expert Insight
- **Broder (1997):** MinHash for web dedup.
- **Lee et al. (2021), "Deduplicating Training Data Makes Language Models Better":** less memorization, same or better perplexity; exact substring dedup with suffix arrays.
- FineWeb found *per-snapshot* MinHash dedup better than global dedup (global over-removed high-quality content that appeared repeatedly).
