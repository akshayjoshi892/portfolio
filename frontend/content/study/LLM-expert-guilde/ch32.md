## 32.1 The Llama Architecture, Change by Change

### 🧭 The Problem First
GPT-2's design (2019) has known inefficiencies: LayerNorm's mean subtraction is unnecessary, GELU MLPs underperform gated ones, learned absolute positions don't extrapolate, biases add little, and the MHA KV cache is large.

### 💡 Intuition / Instinct
Each change is small and independently justified (you've built every piece already):

| Component | GPT-2 | Llama-style | Why |
|---|---|---|---|
| Norm | LayerNorm | **RMSNorm** | cheaper, same quality (Ch 10.2) |
| MLP | GELU 4C | **SwiGLU 8/3·C** | better loss at equal params (Ch 9.4) |
| Position | learned absolute | **RoPE** | relative, extensible (Ch 18.5) |
| Biases | yes | **none** | fewer params, more stable |
| Attention | MHA | **GQA** | smaller KV cache (Ch 30.3) |
| Embeddings | tied | untied (large) / tied (small) | capacity vs params |
| Optional | — | **QK-norm**, z-loss | stability (Ch 27) |

### 🖼️ Visual Mental Model

```text
 x ──┬──────────────────────────(+)──┬───────────────────────(+)──▶
     └─ RMSNorm ─ GQA(RoPE on q,k) ┘ └─ RMSNorm ─ SwiGLU ─────┘
 final: RMSNorm → lm_head
```

### 📐 The Math, Gently
Params per block (no biases): attention $C\cdot(H + 2H_{kv})D + C^2$; SwiGLU $3\cdot C\cdot F$ with $F ≈ \frac83C$ rounded up to a multiple of 256; norms 2C.
Example: C = 2048, H = 16, H_kv = 4, D = 128, F = 5632: attention = 2048·(2048 + 1024) + 2048² ≈ 10.5M; MLP = 3·2048·5632 ≈ 34.6M; ≈ 45.1M per block.

### 🛠️ Build It From Scratch

```python
# nanoforge/models/llama.py
import math
from dataclasses import dataclass
import torch, torch.nn as nn, torch.nn.functional as F
from nanoforge.nn import RMSNorm
from nanoforge.models.rope import apply_rope
from nanoforge.models.attention import repeat_kv

@dataclass
class LlamaConfig:
    vocab_size: int = 8192
    block_size: int = 1024
    n_layer: int = 8
    n_head: int = 8
    n_kv_head: int = 2
    n_embd: int = 512
    ffn_mult: float = 8 / 3
    multiple_of: int = 64
    rope_base: float = 10000.0
    rope_scaling: dict = None          # {"type": "linear"|"ntk"|"yarn", "factor": s, "orig_len": L}
    norm_eps: float = 1e-5
    qk_norm: bool = False
    tie_embeddings: bool = True
    sliding_window: int = None         # e.g. 256 -> local attention
    dropout: float = 0.0
    z_loss: float = 0.0

def llama_rope_cache(cfg, device=None):
    D = cfg.n_embd // cfg.n_head
    inv_freq = rope_inv_freq(D, cfg.rope_base, cfg.rope_scaling)          # 32.2
    t = torch.arange(cfg.block_size, device=device, dtype=torch.float32)
    freqs = torch.outer(t, inv_freq.to(device))
    mscale = yarn_mscale(cfg.rope_scaling)                                  # 1.0 unless YaRN
    return (freqs.cos() * mscale), (freqs.sin() * mscale)

class LlamaAttention(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.H, self.Hkv, self.D = cfg.n_head, cfg.n_kv_head, cfg.n_embd // cfg.n_head
        self.wq = nn.Linear(cfg.n_embd, self.H * self.D, bias=False)
        self.wk = nn.Linear(cfg.n_embd, self.Hkv * self.D, bias=False)
        self.wv = nn.Linear(cfg.n_embd, self.Hkv * self.D, bias=False)
        self.wo = nn.Linear(self.H * self.D, cfg.n_embd, bias=False); self.wo.RESIDUAL_SCALE = True
        self.q_norm = RMSNorm(self.D, cfg.norm_eps) if cfg.qk_norm else nn.Identity()
        self.k_norm = RMSNorm(self.D, cfg.norm_eps) if cfg.qk_norm else nn.Identity()
        self.window, self.dropout = cfg.sliding_window, cfg.dropout

    def forward(self, x, cos, sin, cache=None, layer_idx=None):
        B, T, C = x.shape
        q = self.q_norm(self.wq(x).view(B, T, self.H, self.D)).transpose(1, 2)
        k = self.k_norm(self.wk(x).view(B, T, self.Hkv, self.D)).transpose(1, 2)
        v = self.wv(x).view(B, T, self.Hkv, self.D).transpose(1, 2)
        off = cache.pos if cache is not None else 0
        q, k = apply_rope(q, cos[off:off + T], sin[off:off + T]), apply_rope(k, cos[off:off + T], sin[off:off + T])
        if cache is not None: k, v = cache.update(layer_idx, k, v)
        Tk = k.size(2)
        k, v = repeat_kv(k, self.H // self.Hkv), repeat_kv(v, self.H // self.Hkv)
        if self.window is None and (cache is None or off == 0):
            y = F.scaled_dot_product_attention(q, k, v, is_causal=T > 1,
                                               dropout_p=self.dropout if self.training else 0.0)
        else:
            qi = torch.arange(Tk - T, Tk, device=x.device)[:, None]; kj = torch.arange(Tk, device=x.device)[None]
            mask = kj <= qi
            if self.window is not None: mask &= (qi - kj) < self.window
            y = F.scaled_dot_product_attention(q, k, v, attn_mask=mask)
        return self.wo(y.transpose(1, 2).contiguous().view(B, T, C))

class SwiGLUMLP(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        F_ = int(cfg.ffn_mult * cfg.n_embd); F_ = cfg.multiple_of * math.ceil(F_ / cfg.multiple_of)
        self.w_gate = nn.Linear(cfg.n_embd, F_, bias=False)
        self.w_up = nn.Linear(cfg.n_embd, F_, bias=False)
        self.w_down = nn.Linear(F_, cfg.n_embd, bias=False); self.w_down.RESIDUAL_SCALE = True
    def forward(self, x): return self.w_down(F.silu(self.w_gate(x)) * self.w_up(x))

class LlamaBlock(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.attn_norm = RMSNorm(cfg.n_embd, cfg.norm_eps); self.attn = LlamaAttention(cfg)
        self.mlp_norm = RMSNorm(cfg.n_embd, cfg.norm_eps); self.mlp = SwiGLUMLP(cfg)
    def forward(self, x, cos, sin, cache=None, layer_idx=None):
        x = x + self.attn(self.attn_norm(x), cos, sin, cache, layer_idx)
        return x + self.mlp(self.mlp_norm(x))

class Llama(nn.Module):
    def __init__(self, cfg: LlamaConfig):
        super().__init__()
        self.cfg = cfg
        self.tok_emb = nn.Embedding(cfg.vocab_size, cfg.n_embd)
        self.layers = nn.ModuleList([LlamaBlock(cfg) for _ in range(cfg.n_layer)])
        self.norm = RMSNorm(cfg.n_embd, cfg.norm_eps)
        self.lm_head = nn.Linear(cfg.n_embd, cfg.vocab_size, bias=False)
        if cfg.tie_embeddings: self.tok_emb.weight = self.lm_head.weight
        cos, sin = llama_rope_cache(cfg)
        self.register_buffer("rope_cos", cos, persistent=False); self.register_buffer("rope_sin", sin, persistent=False)
        self.apply(self._init)

    def _init(self, m):
        if isinstance(m, nn.Linear):
            std = 0.02 * ((2 * self.cfg.n_layer) ** -0.5 if getattr(m, "RESIDUAL_SCALE", False) else 1.0)
            nn.init.normal_(m.weight, 0.0, std)
        elif isinstance(m, nn.Embedding): nn.init.normal_(m.weight, 0.0, 0.02)

    def forward(self, idx, targets=None, cache=None, all_logits=False):
        x = self.tok_emb(idx)
        for i, layer in enumerate(self.layers):
            x = layer(x, self.rope_cos, self.rope_sin, cache, i)
        if cache is not None: cache.advance(idx.size(1))
        x = self.norm(x)
        if targets is None and not all_logits:
            return self.lm_head(x[:, [-1], :]), None
        logits = self.lm_head(x)
        if targets is None: return logits, None
        loss = F.cross_entropy(logits.view(-1, logits.size(-1)).float(), targets.view(-1), ignore_index=-100)
        if self.cfg.z_loss: loss = loss + self.cfg.z_loss * torch.logsumexp(logits.float(), -1).pow(2).mean()
        return logits, loss

    def num_params(self, non_embedding=False):
        n = sum(p.numel() for p in self.parameters())
        return n - self.tok_emb.weight.numel() if non_embedding else n

LLAMA_CONFIGS = {
    "nano":  dict(n_layer=4,  n_head=4,  n_kv_head=2, n_embd=128, block_size=256),
    "micro": dict(n_layer=6,  n_head=6,  n_kv_head=2, n_embd=384, block_size=512),
    "mini":  dict(n_layer=8,  n_head=8,  n_kv_head=2, n_embd=512, block_size=1024),
    "small": dict(n_layer=12, n_head=12, n_kv_head=4, n_embd=768, block_size=2048),
}
```

(The functions `rope_inv_freq` and `yarn_mscale` are defined in 32.2 and live in the same file. `KVCache` from Ch 30 works unchanged with `H_kv = n_kv_head`.)

## 32.2 Long Context: RoPE Scaling (Position Interpolation, NTK, YaRN)

### 🧭 The Problem First
You trained with a 2K context. Users want 16K. Feeding positions beyond 2K gives RoPE angles the model has never seen, and quality collapses immediately.

### 💡 Intuition / Instinct
- **Position Interpolation (PI):** squeeze the new positions into the trained range by dividing them by the scale factor s (positions 0–16K behave like 0–2K). All frequencies are compressed equally, so high-frequency (local) dimensions lose resolution, but a short fine-tune (~1K steps) recovers it.
- **NTK-aware scaling:** increase the RoPE *base* instead, so high frequencies (local detail) are barely changed and low frequencies (long range) are interpolated. It works reasonably even without fine-tuning.
- **YaRN:** per-frequency treatment (don't touch high frequencies, interpolate low ones, blend in between) plus an attention temperature correction. The best results with a short fine-tune.

### 🖼️ Visual Mental Model

```text
 frequency index i:   high freq (local) ────────────────── low freq (global)
 PI:                  compress /s        compress /s          compress /s
 NTK:                 ~unchanged         partially            compress
 YaRN:                unchanged          ramp blend           compress /s   (+ temperature)
```

### 📐 The Math, Gently
Base frequencies: $\theta_i = b^{-2i/D}$.
- PI: $\theta_i' = \theta_i / s$.
- NTK-aware: $b' = b\cdot s^{D/(D-2)}$.
- YaRN: with wavelength $\lambda_i = 2\pi/\theta_i$ and ratio $r_i = L_{orig}/\lambda_i$, use $\gamma(r) = \text{clip}\left(\frac{r - \alpha}{\beta - \alpha}, 0, 1\right)$ (α = 1, β = 32); $\theta_i' = (1-\gamma)\frac{\theta_i}{s} + \gamma\theta_i$; attention scale $m = 0.1\ln s + 1$ (applied to cos/sin, which multiplies the logits by m²).

### 🛠️ Build It From Scratch

```python
# nanoforge/models/llama.py (top-level helpers)
import math, torch
def rope_inv_freq(D, base=10000.0, scaling=None):
    inv = 1.0 / (base ** (torch.arange(0, D, 2, dtype=torch.float32) / D))
    if not scaling: return inv
    s, typ = scaling["factor"], scaling["type"]
    if typ == "linear":                                   # Position Interpolation
        return inv / s
    if typ == "ntk":
        base2 = base * s ** (D / (D - 2))
        return 1.0 / (base2 ** (torch.arange(0, D, 2, dtype=torch.float32) / D))
    if typ == "yarn":
        L0, alpha, beta = scaling["orig_len"], scaling.get("alpha", 1.0), scaling.get("beta", 32.0)
        ratio = L0 / (2 * math.pi / inv)                  # how many full rotations within the original context
        gamma = ((ratio - alpha) / (beta - alpha)).clamp(0, 1)
        return (1 - gamma) * (inv / s) + gamma * inv
    raise ValueError(typ)

def yarn_mscale(scaling):
    if scaling and scaling.get("type") == "yarn":
        return 0.1 * math.log(scaling["factor"]) + 1.0
    return 1.0
```

- Forgetting that the training data must actually *contain* long sequences for fine-tuning.

### 🧠 Expert Insight
- **Chen et al. (2023), Position Interpolation.** **bloc97 (2023), NTK-aware (Reddit/blog).** **Peng et al. (2023), YaRN.**
- **Llama 3.1:** extended 8K → 128K with a frequency-dependent scaling and staged long-context training.
- **Xiong et al. (2023), "Effective Long-Context Scaling":** increase the RoPE base and continue pretraining on long data.

### ✅ Check Your Instinct
1. Why does PI hurt local precision?
2. What does YaRN leave untouched?

<details><summary>Answers</summary>

1. It compresses the high-frequency dimensions too, reducing the angular resolution between nearby tokens.
2. The high-frequency (short-wavelength) dimensions.
</details>

### 📌 Recap Card
- PI: divide positions by s; NTK: raise the base; YaRN: per-frequency blend + temperature.
- Always fine-tune briefly on long data.
- Evaluate with position-bucketed perplexity and retrieval tests.

> **Core intuition:** *Stretch the slow clocks to cover more time; leave the fast clocks alone.*

## 32.3 Sliding-Window and Local/Global Attention

### 🧭 The Problem First
Full attention costs O(T²) compute and an O(T) KV cache per layer. For long contexts, most layers mostly need *local* context.

### 💡 Intuition / Instinct
**Sliding-window attention (SWA):** each token attends only to the last W tokens. Compute is O(T·W) and the cache holds only W positions per layer (a rolling buffer). Stacked layers still propagate information further: after L layers the receptive field is ≈ L·W. **Local/global interleaving:** most layers local (W = 4K), every k-th layer global. You get most of the quality at a fraction of the cost.

### 🖼️ Visual Mental Model

```text
 window W=3 mask:        receptive field grows with depth:
 ■                       layer 1: 3 tokens
 ■■                      layer 2: 5 tokens
 ■■■                     layer L: ~L·W tokens
 ·■■■
 ··■■■
```

### 📐 The Math, Gently
The mask: $M_{ij} = [j \le i]\cdot[i - j < W]$. The cache per layer is bounded by W instead of T. With a 1:5 global:local ratio, the cache ≈ (1/6)·T + (5/6)·W per layer on average.

### 🛠️ Build It From Scratch
Already supported: `LlamaConfig(sliding_window=W)` applies the windowed mask (32.1). For interleaving:

```python
class HybridLlama(Llama):
    """Every `global_every`-th layer is global; others use a sliding window."""
    def __init__(self, cfg, window=256, global_every=4):
        super().__init__(cfg)
        for i, layer in enumerate(self.layers):
            layer.attn.window = None if (i + 1) % global_every == 0 else window
```

For the rolling KV cache (inference), replace `KVCache.update` for local layers with a circular buffer of size W; the positions for RoPE still use the absolute `cache.pos`.

### 🔬 Experiment & Observe
Train micro with full attention vs W = 64 everywhere vs hybrid (W = 64, a global layer every 3), at T = 512 on TinyStories. The val losses are close (stories are local), while the hybrid is cheaper at long T. On a task needing long-range retrieval (passkey), pure SWA fails beyond ≈ L·W, and the hybrid succeeds.

### ⚠️ Failure Modes & Debugging
- Explicit boolean masks disable the fastest SDPA path. Use FlashAttention's `window_size` or FlexAttention in production.
- Assuming the receptive field L·W equals effective use: information degrades over many hops.

### 🧠 Expert Insight
- **Beltagy et al. (2020), Longformer**; **Child et al. (2019), Sparse Transformer.**
- **Mistral 7B (2023):** SWA W = 4096 with a rolling cache.
- **Gemma 2/3:** interleaved local (4K/1K window) and global layers (Gemma 3 uses a 5:1 local:global ratio).
- **Xiao et al. (2023), StreamingLLM:** keep "attention sink" tokens (the first few) plus a recent window for infinite streaming.

### ✅ Check Your Instinct
1. Receptive field with 32 layers and W = 4096?
2. Why keep some global layers?

<details><summary>Answers</summary>

1. ≈ 131K tokens (theoretical).
2. For precise long-range retrieval that multi-hop propagation can't do reliably.
</details>

### 📌 Recap Card
- SWA: attend to the last W tokens; bounded cache.
- Receptive field ≈ L·W.
- Local/global interleaving keeps long-range ability.

> **Core intuition:** *Most thinking is local; keep a few layers with a view of the whole page.*
